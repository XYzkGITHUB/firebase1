# **App Name**: IRGG Luxe Surface

## Core Features:

- Immersive 'IRGG' Interactive Hero: A high-end, full-screen visual gateway featuring a reactive TextHoverEffect on the company name to establish immediate premium positioning.
- AI Ceramic Material Tool: A specialized tool that allows users to upload site photos or project requirements to receive curated recommendations for porcelain, laminate, and sanitary ware based on project logic.
- Advanced Product Explorer: Interactive, highly filterable grid for Keramogranit, Laminate, SPS, and Plumbing categories with deep-zoom image previews.
- Real-time Supply Chain Tracker: A customer-facing dashboard for tracking maritime and air shipments from factory contracts directly to the object location.
- B2B Developer Hub: Specialized interface for large-scale builders and architects to manage documentation, bulk pricing, and custom project specifications.
- AI Logistic Forecasting Tool: Analyzes project timelines and current shipping lane data to provide precise delivery estimation for large architectural projects.
- Intelligent Request Management: Comprehensive lead generation system with input validation and conditional logic to routing requests for customs and warehouse services.

## Style Guidelines:

- Primary Color: Polished Warm Grey (#C9C3BC) evoking architectural stone and sophistication.
- Background Color: Deep Onyx (#141312) to provide a luxurious contrast, referencing slate textures.
- Accent Color: Burnished Copper (#8B5E3C) for strategic CTAs and maritime logistics highlighting.
- Headline font: 'Playfair Display' for an elegant, high-end serif feel. Body font: 'Inter' for objective, machine-precise readability. Use 'Source Code Pro' for technical logistics data.
- Thin-line architectural icons (outline style) inspired by IRGG brand language, utilizing subtle stroke animations on interaction.
- Cinematic full-height sections with asymmetric grids for showcase projects and plenty of negative space to signify luxury.
- Smooth parallax scrolling for stone textures and elastic hover transitions on all product cards to simulate weight and quality.
